## 1. Executive Summary & Problem Statement

In traditional subscription models (e.g., Netflix, Spotify, AWS, SaaS), users incur irreversible monthly recurring expenses ("sunk costs"). Once charged, subscription capital is permanently forfeited.

**PoolPass** introduces a **lossless, yield-funded subscription protocol**:
1. **Principal Preservation:** The subscriber deposits an upfront stake of stablecoins (`mUSDC`) into a yield-generating lending pool (`MockYieldPool.sol` simulating Aave/Compound).
2. **Automated Yield Redirection:** Interest generated by the staked collateral is redirected to pay the recurring subscription fee to the service provider/treasury.
3. **100% Principal Recovery:** When the commitment lock duration matures, the user can withdraw 100% of their initial deposit, or re-stake to renew their pass without touching their wallet funds.
4. **Duration-Adjusted Incentive Math:** Longer lock durations unlock higher effective APY tiers and loyalty discounts, directly reducing the required upfront stake.

---

## 2. Mathematical Model: Duration-Adjusted Staking

The required stake $S$ is calculated dynamically based on the monthly fee $F_{mo}$, duration $T$, annual rate $APY$, and duration loyalty discount $D$:

$$\text{Total Subscription Fee: } F_{total} = F_{mo} \times \frac{T}{30\text{ days}}$$

$$\text{Base Stake: } S_{base} = \frac{F_{total} \times 365\text{ days} \times 10000}{T \times \text{APY}_{bps}}$$

$$\text{Duration-Adjusted Stake: } S = S_{base} \times \frac{10000 - \text{Discount}_{bps}}{10000}$$

### Tier Schedule Configured in Smart Contracts:

| Plan | Monthly Nominal Fee | 30-Day Lock (12% APY, 0% Disc.) | 90-Day Lock (15% APY, 5% Disc.) | 180-Day Lock (18% APY, 10% Disc.) | 365-Day Lock (24% APY, 20% Disc.) |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **Basic Pass** | $5.00 | ~506.94 mUSDC | ~385.28 mUSDC | ~304.17 mUSDC | **~202.78 mUSDC** |
| **Pro Pass** | $15.00 | ~1,520.83 mUSDC | ~1,155.83 mUSDC | ~912.50 mUSDC | **~608.33 mUSDC** |
| **Enterprise Pass** | $50.00 | ~5,069.44 mUSDC | ~3,852.78 mUSDC | ~3,041.67 mUSDC | **~2,027.78 mUSDC** |

*Notice:* Locking for 1 year reduces required upfront stake by **over 60%**!

## 3. Architecture & Contract Breakdown

```
+-------------------------------------------------------------------------+
|                              USER WALLET                                |
+-------------------------------------------------------------------------+
       |                                              ^
 1. Approve & Stake                               6. Withdraw 100%
   Required Stake                                 Principal upon Lock
       |                                            Maturity
       v                                              |
+-------------------------------------------------------------------------+
|                             PoolPass.sol                                |
|  - Manages subscription tiers & lock timestamps                         |
|  - Computes duration-adjusted stake quotes                              |
|  - Enforces early-withdrawal restrictions                               |
|  - Directs yield payouts to provider treasury                           |
+-------------------------------------------------------------------------+
       |                                              ^
 2. Deposits Collateral                           5. Withdraws Principal
       |                                              |
       v                                              |
+-------------------------------------------------------------------------+
|                          MockYieldPool.sol                              |
|  - Simulates Aave/Compound lending pool                                 |
|  - Accrues interest deterministically over time                         |
+-------------------------------------------------------------------------+
       |
 3. Accrues Yield
       |
       v (4. Harvest / Settle Yield)
+-------------------------------------------------------------------------+
|                     TREASURY / SERVICE PROVIDER                         |
|  - Receives recurring subscription revenue generated purely by yield    |
+-------------------------------------------------------------------------+
```

### Contracts:
- `MockERC20.sol`: Standard ERC-20 token representing stablecoins (`mUSDC`, 18 decimals) with a public faucet for demoing.
- `MockYieldPool.sol`: Simulates deterministic lending APY (12% - 24%) with timestamp-based linear accrual.
- `PoolPass.sol`: Core protocol orchestrating plan registration, duration-adjusted stake verification, time locks, yield harvesting, and principal protection.

## 4. Quick Start: Local End-to-End Execution

### Step 1: Install Dependencies
Open a terminal in the project root:
```bash
npm install
cd frontend && npm install && cd ..
```

### Step 2: Start Local Blockchain Node
Start the local Hardhat JSON-RPC node:
```bash
npm run node
```
*Keep this terminal running. It hosts the local blockchain at `http://127.0.0.1:8545` (Chain ID: `31337`).*

### Step 3: Run Automated Test Suite
In a second terminal, verify the smart contract test suite:
```bash
npm test
```
*Expected Output: All 10 unit & integration tests passing.*

### Step 4: Deploy Smart Contracts Locally
Deploy contracts, seed the mock yield pool, and export ABIs to the frontend:
```bash
npm run deploy:local
```

### Step 5: Start the React Frontend dApp
Launch the local Vite development server:
```bash
npm run frontend:dev
```
Open your browser at: **`http://localhost:5173`**

## 5. College Viva / Demo Walkthrough (PBL Presentation)

Follow this 5-minute step-by-step flow during evaluation:

1. **Deterministic Test Accounts:**
   - In the frontend header, keep **"Local Test Wallets"** selected and choose **"Alice (Test Subscriber)"**.
   - Notice Alice already has a pre-funded test balance of `10,000 mUSDC`.
2. **Observe Duration-Adjusted Staking:**
   - In the **"1. Select Lock Duration"** bar, toggle between **1 Month (30d)** and **1 Year (365d)**.
   - Point out to the evaluator how the required stake for **Pro Pass** drops from **1,520 mUSDC** to **608 mUSDC** due to duration incentives.
3. **Stake & Subscribe:**
   - Click **"Stake & Subscribe"** on Pro Pass.
   - The dApp automatically approves token allowance and calls `subscribe()`.
   - The **"Active Subscription"** dashboard appears immediately showing the lock expiry countdown, staked principal, and yield progress.
4. **Demonstrate Time-Travel & Yield Accrual:**
   - Under the **"College Demo Simulation Panel"**, click **"+7 Days"** or **"+30 Days (1 Mo)"**.
   - The dApp executes `evm_increaseTime` and `evm_mine` on the local node.
   - Watch the **Accrued Yield** increase in real-time, matching the subscription fee target!
5. **Settle Yield to Service Provider:**
   - Click **"Settle Yield"**.
   - The accrued yield is harvested and routed to the **Provider Treasury Revenue** counter at the top.
   - Note that Alice's principal is **100% untouched**!
6. **Early-Withdrawal Prevention & Post-Lock Recovery:**
   - Try to withdraw before maturity: the contract rejects early withdrawals to protect the service agreement.
   - Click **"+365 Days"** in the demo panel to fast-forward past maturity.
   - The status updates to **"Matured (Unlocked)"** and the **"Withdraw Principal"** button lights up.
   - Click **"Withdraw Principal"**: 100% of Alice's staked principal is returned to her wallet balance.
